# Tokens Definition

## Values

Int: `[0-9]+`  
Float: `[0-9]+\.[0-9]*`  
Str: `"([^\\]|\\\.)*"`  
Char: `'([^\\]|\\\.)'`

## Keywords

True: `true`  
False: `false`  
Bind: `bind`  
If: `if`  
Else: `else`  
Fn: `fn`

## Symbols

`[a-zA-Z_][a-zA-Z0-9_]*`

## Operators

**Structure**

Lparen: `(`  
Rparen: `)`  
Lbrack: `[`  
Rbrack: `]`  
Lbrace: `{`  
Rbrace: `}`  
Comma: `,`  
Semicolon: `;`

**Types**

To: `->`

**Comparison**

Eq: `=`  
Neq: `!=`  
Gt: `>`  
Ge: `>=`  
Lt: `<`  
Le: `<=`

**Arithmetic**

Add: `+`  
Sub: `-`  
Mul: `*`  
Div: `/`  
Mod: `%`

**logic**

And: `&`  
Or: `|`  
Not: `!`  
Xor: `^`
