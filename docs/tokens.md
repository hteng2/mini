# tokens definition

| token              | regex                  |
| ------------------ | ---------------------- |
| numbers            |                        |
| `Num`              | `[0-9][0-9]*`          |
| keywords           |                        |
| `True`             | `true`                 |
| `False`            | `false`                |
| `Let`              | `let`                  |
| `Var`              | `var`                  |
| `Print`            | `print`                |
| `If`               | `if`                   |
| `Then`             | `then`                 |
| `Else`             | `else`                 |
| `End`              | `end`                  |
| `While`            | `while`                |
| `Do`               | `do`                   |
| `Done`             | `done`                 |
| `Name`             | `[a-zA-Z][a-zA-Z0-9]*` |
| operators          |                        |
| `Lparen`           | `(`                    |
| `Comma`            | `,`                    |
| `Rparen`           | `)`                    |
| ordered comparison |                        |
| `Eq`               | `=`                    |
| `Gt`               | `>`                    |
| `Lt`               | `<`                    |
| arithmetic         |                        |
| `Add`              | `+`                    |
| `Sub`              | `-`                    |
| `Mul`              | `*`                    |
| `Div`              | `/`                    |
| `Mod`              | `%`                    |
| logic              |                        |
| `And`              | `&`                    |
| `Or`               | `\|`                   |
| `Not`              | `!`                    |
| `Xor`              | `^`                    |
